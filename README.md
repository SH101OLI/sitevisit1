# Igloo Site Visit Assessment

Installable phone app for Igloo site visits. Open https://sh101oli.github.io/sitevisit1/ on a phone and choose **Add to Home Screen**.

Visit data stays on the device (or the user's OneDrive); this repo only holds the blank app.

To update: replace `index.html` and bump `VERSION` in `sw.js` so installed phones pick up the change.
